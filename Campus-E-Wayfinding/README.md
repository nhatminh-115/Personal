# Campus E Wayfinding

Interactive 3D wayfinding prototype for UEH Campus E.

## Features

- Full-building, route-floor and single-floor views
- Automatic CT1, CT2 or elevator selection
- Animated directional arrows and start/destination markers
- Floor-specific rooms, doors, restrooms and vertical circulation
- Routes follow corridor paths instead of crossing rooms

The navigation is indicative and does not replace the building's official emergency-exit plan.
